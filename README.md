# Hi, I'm Tuna

I work as a Software Engineer at Bank of America. Outside of work, I build products, work on applied machine learning research, and join hackathons when the problem is worth solving.

## Selected work

### [PickupCard](https://pickupcard.app)

I co-founded PickupCard and helped take it from zero to the App Store in about a month. It is a consumer sports app built around making pickup matches more organized and competitive.

### [Groundwater contamination research](https://github.com/tunakurucu/sentinel2-groundwater-contamination)

I am the first author of research using Sentinel-2 imagery and deep learning to estimate groundwater contamination patterns from vegetation signals. The first version was published in the ISASC 2026 conference proceedings and presented in Konya. An extended version has been submitted to the Selçuk Journal of Agriculture and Food Sciences.

### [SleepSense](https://github.com/raj-chinagundi/treehacks-26)

A TreeHacks 2026 project combining an ESP32 sensing device with a web platform. I worked on the frontend design and helped with the product and business direction.

### [AI News](https://github.com/tunakurucu/ai-news-system) and [Made3D](https://github.com/tunakurucu/Made3D)

These projects were originally created by [mithdreamer](https://github.com/mithdreamer). I joined later to help make them more functional and reliable through API integrations, AI features, testing, and full website redesigns.
